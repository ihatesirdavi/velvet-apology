# Lumenwave — public codename product rules

- Single product home only; no shared FE/MINT/BE infrastructure or duplicate services.
- Keep original code, artwork, internal source paths, identities, branch refs, host/network details and private project names out of this public repository until separately approved.
- Use the existing frontend/interface, integration/evidence and backend/runtime responsibility contracts; source owners retain original authority.
- Admit a bounded module only after confirmed original owner, exact SHA, third-party rights, accepted import mapping, source tests and receiving-owner ACK.
- Test real native build and installation separately; a README, test mock or graphic preview is not a released application.
- Keep public release disabled until owner acceptance, signed artifact/rollback receipt and real desktop/mobile visual review.
