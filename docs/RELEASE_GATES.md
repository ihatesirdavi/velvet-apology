# Release gates
State: PUBLIC STAGING ONLY, NO IMPORTED SOURCE.

- [ ] Original-owner source qualification, fresh Git SHA and clean worktree
- [ ] Scoped module import map, licensing and media rights
- [ ] Original-source OFFER and receiving-owner ACK
- [ ] Source tests, reproducible build, dependency/license inventory and artifact digest
- [ ] Native installation/loading tests and rollback
- [ ] Responsive visual review with actual project imagery, where applicable
- [ ] Separate approval for any public code, assets, binary, product listing or release

No automatic synchronization, new runner, installer, daemon or CI system is provided.
